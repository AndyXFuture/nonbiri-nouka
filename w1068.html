第1068话 亚梅回到岛上

Web 版 第 1068 话 · 已润色

（作者：跟#1059撞标题了，修正#1059）

<br/>

我的名字叫亚梅。

<br/>

村长得知我是恶魔帝国的初代国王后，烦恼着该怎么称呼我。

亚梅大人、亚梅帝之类的。

我告诉他，像平常一样叫亚梅小姐，或者直接叫亚梅就行了。

<br/>

回岛上之前，我在村里逛了一圈。

上次来的时候也逛过，这次则是一边找有没有什么能带回岛上的东西。

我一边想着，如果岛上能有马、牛、山羊、鸡之类的该有多好，一边又觉得万一它们不适应岛上的生活，那也太可怜了。

岛上不需要那些追着我跑的山羊。

山羊在我眼里，就是扰乱我安宁的存在。

哼，别过来。

事到如今就算装出撒娇的样子也没用。

反正肯定又想趁我不备。

你看，好几只都绕到我背后去了。

才这么想着，右边就挨了一记头槌。

原来背后那些也是诱饵啊。

我一边飞上天空，一边发誓再也不靠近村里的山羊。

<br/>

蜜蜂们正忙着准备过冬。

在忙碌的蜂巢里还能躺着呼呼大睡的胖女王蜂，精神强度真是惊人。

虽然并不值得敬佩。

我听了那蜂巢里工蜂们的抱怨，它们便分了些蜂蜜给我。

又甜又好吃。

谢啦。

<br/>

乌尔莎不知怎地，总在照顾那些小孩子。

看到那种光景，会觉得她就是个普通的女孩子啊～。

所以，你们在跟孩子们做什么呢？

晒柿子干？

哦～。

那是拉丝蒂的最爱啊。

不错呢。

不过，要是不同样为哈克莲做点什么，她不会闹别扭吗？

龙族会因为超级无聊的小事闹脾气的。

预定是要给哈克莲苹果派对吧？

苹果就是那个很大颗的阿波吧。

那看起来很好吃。

啊，不，我不是在跟你讨。

苹果派是给哈克莲的。

我会拜托村长，在岛上种阿波……不对，种苹果树。

<br/>

露露西＝露。

在村长的妻子们当中地位最高的吸血鬼。

目前怀孕中。

……咦？

吸血鬼会怀孕的吗？

嗯，嘛，细节就别在意了。

听说她已经生过两个孩子了。

我向她道了声恭喜。

之前被乌尔莎带过去时，我们见过面。

也不算是不认识的关系。

我和露的长子阿尔弗雷德是初次见面。

他是担心怀孕的露，所以回来的吗？

你好～。

嗯？

要我到离露远一点的地方？

是可以啦。

<br/>

我正想着怎么了，结果阿尔弗雷德变了模样。

啊～，该说是年龄变大了的感觉吧。

「我名为阿尔弗雷德！阿尔弗雷德＝马奇欧！虽诞生自伟大的父亲与母亲，却仍是尚无所成的后生晚辈！然而，我怀抱着终有一日将变革世界的志向！」

哦哦，这精心设计的姿势！

对对对，吸血鬼就是这么回事。

因为露和始祖大人他们太普通了，我都给忘了。

既然人家打了招呼，就得回礼。

这是理所当然的。

我努力收集体内的魔力，让身体成长。

阿尔弗雷德大概相当于人类的二十岁左右，那我就变成人类二十岁出头。

毕竟我年纪比较大嘛。
