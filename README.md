抓日文原文 → 民间译文打底 → 以文库版 EPUB 为唯一术语基准校准 → 润色 → 七项质检。

### TMX 翻译记忆库
- 段落级 130,277 条 + 整话级 977 条日↔中对照
- 对齐算法：① 段长序列 Pearson 相关性定位整体偏移 ② 带状 DTW 修正局部漂移
- 目标区间（819 话之后）高置信对齐（对角占比 ≥0.90）约 96%

### 术语校准
- 以文库版 17 卷为语料 A、民间译文为语料 B，n-gram 频次差集 → 候选 → **回日文原文裁决**
- 352 条映射，详见站点「译名字典」
- 三条教训：
  1. **伪配对**：仅凭共享汉字会配出无关词（缮王国/严王国实为两个不同王国）
  2. **组合效应**：一轮替换会改变文本导致后续规则失配，必须多遍迭代至收敛
  3. **大模型规范化建议方向常是反的**：台湾译本用「营运/诈欺/热中」，须先统计语料再决定

### 机器翻译 + 人工指导修正
- 无状态调用：system = 翻译规则 + 术语表 + 风格范例；user = 日文原文
- 段号标记 ⟦n⟧ 强制保持段落结构，杜绝模型擅自合并段落
- 术语校验用「最长完整匹配 + 片假名词串边界判定」，避免子串误报
- 18 卷（819–867 话）做过五轮逐章审校，修正约 1,700 处
